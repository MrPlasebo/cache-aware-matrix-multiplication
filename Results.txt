Cache-Aware Optimization of Matrix Multiplication
Experimental Results

Environment:
- Linux / WSL Ubuntu
- GCC compiler
- Programming Language: C
- Same random seed used for both implementations

Project Goal:
This project compares a naive matrix multiplication implementation with an optimized version.
The optimized version changes the loop order to improve memory access behavior.

------------------------------------------------------------
Test 1 - Matrix Size: 1000 x 1000
------------------------------------------------------------

Sample Output:
C[0][0] = 20287

Naive Version:
Run 1: 3.194523 seconds
Run 2: 3.100104 seconds
Run 3: 3.090787 seconds
Average: 3.128471 seconds

Optimized Version:
Run 1: 2.412947 seconds
Run 2: 2.396749 seconds
Run 3: 2.404487 seconds
Average: 2.404728 seconds

Difference:
3.128471 - 2.404728 = 0.723744 seconds

Improvement:
23.13%

Observation:
For 1000 x 1000 matrices, the optimized version is significantly faster than the naive version.

Conclusion:
The optimized matrix multiplication version produced the same sample output as the naive version for each matrix size.
This confirms that the optimized version keeps the mathematical result consistent.

The optimized version had lower average execution time in all tests.
The performance improvement became more visible with larger matrix sizes, especially in the 1000 x 1000 test.
This supports the idea that loop order and memory access behavior can affect execution time.
